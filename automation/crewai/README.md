# CrewAI Automation

## Setup
- `python -m venv .venv`
- `.venv\\Scripts\\activate` (Windows)
- `pip install -r requirements.txt`

## Run
- `python src/main.py`

The crew includes all requested agents:
- Operations Manager
- Cultivation Specialist
- Extraction Specialist
- Packaging Specialist
- Financial Analyst
- Database Architect
- Full Stack Developer
- QA Tester
